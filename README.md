
# AI-Based Early Health Risk Detection with Explainable AI (XAI)

## Model Collection

1. Original Heart Disease — UCI dataset
2. Original Diabetes — Pima Indians dataset
3. Kaggle Heart Disease — Cleveland dataset
4. Kaggle Diabetes — Kaggle dataset

## Folder Structure

- models/: saved trained models and preprocessing/XAI artifacts
- datasets/: available cleaned datasets
- reports/: reserved for consolidated reports
- notebooks/: Colab notebook can be placed here

## Important

This project is for educational and research purposes.
Predictions are not medical diagnoses.

Use the saved model pipelines for inference.
Do not fit preprocessing again on patient input.
